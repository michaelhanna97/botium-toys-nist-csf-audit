# 🛡️ NIST Cybersecurity Framework Internal Audit – Botium Toys Case Study

## 📌 Overview
This project is a comprehensive internal cybersecurity audit conducted on the fictional company **Botium Toys**, utilizing the **NIST Cybersecurity Framework (CSF)** as the primary assessment model.  

The audit includes:
- A **Controls Assessment Checklist**
- A **Compliance Checklist** (PCI DSS, GDPR, SOC 1 & 2)
- A **Summary of Recommendations**
- A **Formal Internal Audit Report**

This project demonstrates practical skills in **GRC (Governance, Risk & Compliance)**, **security control evaluation**, **risk assessment**, and **technical report writing** — all highly relevant for roles such as Security Analyst, SOC Analyst, GRC Analyst, and IT Auditor.

## 🎯 Audit Objectives
- Evaluate Botium Toys’ current cybersecurity posture using NIST CSF.
- Identify missing or weak security controls.
- Assess compliance alignment with:
  - **PCI DSS**
  - **General Data Protection Regulation (GDPR)**
  - **SOC 1 / SOC 2**
- Provide actionable, risk-based recommendations.
- Improve confidentiality, integrity, and availability of sensitive data.

## 🔍 Key Findings (Summary)

### 🧩 Missing or Weak Controls
- No **least privilege** enforcement  
- No **separation of duties**  
- No **intrusion detection system (IDS)**  
- No **disaster recovery plan**  
- Weak or missing **password policies**  
- No **encryption** of sensitive customer data  
- No **centralized password management**  
- No **backups** or backup testing  
- Legacy systems require **manual monitoring**

### ⚠️ Compliance Gaps
**PCI DSS**  
- Credit card data is not restricted to authorized users  
- No encryption at transaction or storage points  
- No secure cardholder data environment  
- No strong password policy  

**GDPR**  
- E.U. customer data not fully protected  
- No breach notification plan  
- Data not categorized or inventoried  

**SOC 1 & SOC 2**  
- Missing user access policies  
- Confidentiality of PII/SPII not fully enforced  
- Data availability processes are incomplete  

---

## 🛡 Recommended Improvements
### 🔧 Technical Controls
- Implement **least privilege** access model  
- Enforce **separation of duties** to reduce fraud risk  
- Deploy **IDS** for network monitoring  
- Strengthen password policies (complexity, age, reuse)  
- Encrypt all sensitive data (at rest + in transit)  
- Adopt a **secure password management system**  
- Automate and regularly test backups  
- Replace or automate monitoring of legacy systems  

### 📘 Compliance Improvements
- Align credit card handling with **PCI DSS** requirements  
- Establish privacy safeguards for **GDPR** compliance  
- Implement SOC-compliant access, confidentiality, and availability controls  

### 🚨 Operational Improvements
- Develop and test a **disaster recovery plan**  
- Document security policies and implement regular reviews
